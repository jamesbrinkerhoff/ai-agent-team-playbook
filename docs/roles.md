# How do I split work between AI agents?

Give each agent one job with a clear edge. The edge matters more than the job title. An agent that knows what it does not own will hand work off instead of doing it badly.

## What roles does a small business agent team need?

Our team has seven agents. Yours may need fewer. Start with the jobs that repeat every week.

| Role | Owns |
|---|---|
| Coordinator (chief of staff) | Weekly priority brief for the owner, chasing blocked work, the docs, the model router |
| Media buyer | Ads built as paused drafts, daily cost checks, weekly scorecard, creative briefs |
| Funnel builder | Landing pages, sales pages, checkouts, forms, and the integrations behind them |
| Content studio | Clips, captions, thumbnails, posts, content calendars, video production |
| Event operations | Each live event from registration to follow-up, attendance scorecards |
| Deal desk | Sales call briefs, follow-up and proposal drafts, weekly pipeline cleanup |
| Client delivery | Onboarding, client deliverables, milestones, testimonial permissions |

## What goes in a role file?

Every agent has a `ROLE.md` with the same headings, in the same order:

1. Mission
2. Owns
3. Does not own (route to)
4. Inputs
5. Outputs
6. Tools and connectors
7. Standing rules
8. Routines
9. Handoffs
10. How to run this role from scratch
11. Sources

Use [the template](../templates/ROLE.md).

## Why write "does not own"?

Without it, a helpful agent will take any task it is given. The "does not own" list names the owner for each thing the agent should refuse, so the work still gets done by the right agent.

## How specific should a role be?

Specific enough that a new agent could do the job on day one from the file alone. Name the files it reads, the folders it writes to, and the exact rules it must follow. If you do not know a fact yet, write `TODO` and say what is missing. Never let an agent fill a gap with a guess.

## Should each agent have its own voice?

Yes. Give each role a one-line voice. A media buyer that is "numbers-first and skeptical of vanity metrics" writes different reports from a content agent that "pitches the bold hook first." It makes reports easier to scan and easier to tell apart.
