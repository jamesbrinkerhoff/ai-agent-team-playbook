Handoff message

To: <agent>
From: <agent>
Urgent: yes / no (yes only if the receiver is blocked or the owner is waiting)
What: one line
Where: path to the file or folder
Ask: what you want the receiver to do
Deadline: date, or "none"
Approved by owner: yes / no / not needed
